# RxRelay v1.0.0 release notes

Release date: 2026-08-24

RxRelay v1.0.0 is the first release-ready source state of the medication supply intelligence platform. It combines bounded public-data ingestion, a PostgreSQL-backed Spring API, Kafka status-change processing, Redis caching/rate limiting, and a React review interface in one resource-conscious monorepo.

The release includes the capabilities and verification paths listed in [CHANGELOG.md](../../CHANGELOG.md). The measured local evidence is deliberately separated into [performance.md](../performance.md), [reliability.md](../reliability.md), and [testing.md](../testing.md); those results describe one workstation and do not establish production capacity.

## Upgrade and compatibility

This is the initial release, so there is no prior supported schema to upgrade. Flyway migrations V1–V5 create the current database model. Event contracts remain independently versioned at schema version 1, and REST endpoints use `/api/v1`.

## Publication status

This source state is versioned with a local `v1.0.0` tag and is ready for optional GitHub/Zenodo publication. These notes do not claim that a hosted release, container image, archive record, or DOI already exists.
